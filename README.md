# Moonbow Fairy Quest

A small story game invented by Dahlia. Everything lives in `index.html`; there's no build step.

- **Change names:** edit `CONFIG` at the top of the script.
- **Change story text:** edit `STORY` right below it.
- `scene-art/` holds the original scene mockups the art came from.

Play it at https://jacqueshbastien.github.io/moonbow-fairy-quest/

## Put it on the iPad home screen

1. Open the link above in **Safari** (not Chrome).
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open it from the moonbow icon. It runs full-screen, like an app. Turn the iPad sideways.

Progress saves on the iPad, so she can stop and come back. The small **Start over** button in the bottom-left corner is for grown-ups.

## Updating

Edit `index.html`, then commit and push. GitHub Pages updates the site in a minute or two, and the iPad picks it up the next time the game opens.
